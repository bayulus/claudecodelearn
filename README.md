# Cybersecurity Career Path Advisor

A short, interactive quiz that matches your interests to a cybersecurity career path — SOC Analyst, DFIR, Penetration Tester, Threat Intelligence, Security Engineer, AppSec, GRC, or Cloud Security — and then explains what that role actually involves day to day.

You answer four questions about what kind of work you enjoy (real-time monitoring, investigating after the fact, breaking into systems, research and writing, building tools, coding, or compliance). Your answers are scored against each role, and you get a ranked list of matches. Picking a role shows its summary, day-to-day responsibilities, key skills, and how to get started (certs, practice platforms).

## Files

- **[career-analysis.py](career-analysis.py)** — command-line version. Run with:
  ```
  python career-analysis.py
  ```
- **[career-analysis.html](career-analysis.html)** — browser version with the same quiz logic, styled as a personnel-intake "dossier." No install needed — just open it in any browser.

Both versions contain the same eight roles and scoring logic; the HTML version is purely for a nicer, shareable interface.
